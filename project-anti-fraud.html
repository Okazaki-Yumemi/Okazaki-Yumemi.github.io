【暂时AIGC占位】别点那个链接！把反诈题目变成一次对话

发表于2026-10-11|更新于2026-10-11|项目

“不要点陌生链接”当然是对的。

但现实中的消息不一定会把“陌生”写在脸上。它可能看起来像奖学金通知，可能是一个急着让你付款的人，也可能只是车旁边一张不太起眼的二维码。

《别点那个链接！》是人工智能导论的课程大作业。想做的事情，是把一句正确但有点远的提醒，放进一次具体的选择里。

不先告诉你标准答案

项目设计了奖学金诈骗短信、陌生人催促付款和可疑自行车二维码三个模拟场景。用户需要在对话与操作中作出选择，而不是一进页面就看到一张写满正确答案的宣传图。

前端使用 HTML、CSS 和 JavaScript。离线模拟模式可以演示交互，实时模式则由 Flask 后端连接兼容 OpenAI 格式的 API。这里的场景都是模拟，不需要把真实诈骗消息和个人账号当作演示材料。

做完以后，还能回头看

项目保留交互轨迹，围绕信息来源核验、资金边界、未知入口和紧迫感等方面整理风险复盘，并提供行动清单与 Markdown 报告导出。

相比直接告诉人“你的防骗能力是几分”，我觉得能指出某一步为什么值得停一下，更有实际意义。因为下一次遇到的消息，未必长得和题目一样。

不过这些维度是教学项目中的反馈设计，不是经过独立验证的心理测量，也不能据此断言一个人在现实中一定会被骗或一定安全。

AI 的作用不是制造一个更会骗人的入口

对话可以让情境更具体，但也需要边界。模拟场景应该始终是模拟，真实模式中的 API 凭据也应通过环境配置提供，不放在网页里，更不写进这篇文章。

这是人工智能导论学习记录里单独拿出来的一份项目。它没有解决所有反诈教育的问题，只是尝试让人从“我知道这句话”，走到“遇见这个场景时，我会不会照做”。

中间其实还有挺长的一段路。
