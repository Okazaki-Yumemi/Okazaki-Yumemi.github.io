## 访问统计

本站自访问统计功能启用后开始累计阅读量，不补填历史访问数据。

统计由站主的 Cloudflare Worker 与 D1 提供，记录公开页面路径、分钟级访问时间、国家或地区、设备类别和归类后的来源。只统计目录中已经发布的页面，不记录查询参数、完整来源 URL、原始 User-Agent、原始 IP、姓名或账号。

为估算当天访客数，服务端会临时处理连接 IP 与粗略设备、浏览器类别，使用服务端密钥生成按日变化的 HMAC 标识。数据库只保存这一去标识值，不保存原始 IP，不把它用于跨日关联，也不将其展示给站主。它不是精确人数：共享网络或同类浏览器可能被合并，网络变化也可能重复计数。

同一去标识访客对同一页面在半小时时间段内的重复访问只计一次，并过滤常见爬虫。因此这里的“阅读量”是经过过滤的有效浏览次数，不是服务器原始请求数。

不使用访客跟踪 Cookie，也不在浏览器保存访客身份标识。浏览器的 Do Not Track 或 Global Privacy Control 开启时，不上报访问事件；也可通过每页底部的“统计设置”关闭上报。该选择仅作为偏好保存在当前浏览器，关闭不会追溯删除已经去标识化的记录。

全站及单篇累计阅读量公开显示；访问来源、国家或地区、设备、趋势和最近访问仅站主登录后可见。最近访问记录保留最多 30 天，按日统计及去标识标识保留最多 90 天，过期数据通过每日清理任务删除；累计页面阅读量不含访客标识，长期保留。清理任务不是逐条实时删除，可能存在一个清理周期的延迟。

## 评论

评论使用 Giscus，由博客公开仓库的 GitHub Discussions 保存。只有主动点击“加载评论”才连接 Giscus；加载和登录后，第三方服务会按自己的规则处理必要连接信息。

留言及反应关联公开 GitHub 身份，其他读者可以看到昵称、头像和内容。请勿在评论中提交密码、密钥、票码、联系方式或其他不希望公开的信息。评论可在 GitHub 中按其提供的权限编辑或删除。

## 本机数据与联系

站内音乐使用 sessionStorage 保存播放位置；统计开关使用 localStorage 保存偏好。阅读台使用 localStorage 保存收藏的文章路径、阅读位置和本机阅读时间，不上传服务器，不跨设备同步。移除阅读记录仅清理当前浏览器的对应记录，不影响独立的去标识化访问统计。在线写作后台会在本机保存未发布草稿，只有确认发布才进入公开仓库。这些数据可通过浏览器的站点数据设置清理。

Cloudflare、GitHub 与 Giscus 仍可能为基础设施和安全运维处理连接数据；以上“不保存原始 IP”指本站自行实现的统计数据库，不代表互联网服务链路不存在平台级处理。本站 Worker 的应用日志采集保持关闭。
