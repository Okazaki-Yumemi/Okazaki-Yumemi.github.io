# Target Regeneration Shrinks the Gains of Draft-Training Objectives in Speculative Decoding

> 我们看到新的Loss function 相比于 Cross-Entropy显著提高了Acceptance ， 但是这个增益究竟是来自Loss本身，还是因为训练数据原本就不符合target的输出分布?


# Abstract

1. 核心问题: External Responses 与 Target Responses 不一致
假设我们的训练数据来自于另外一个模型，例如GPT-4 , 而现在希望为Qwen3-8B 训练一个Drafter，那么训练集中的某个位置真实token可以看作是 yt， 而Qwen3-8B在某个位置上最可能生成的数据和y_t不一样。
假如我们直接使用普通的CE，其实是在要求Draft模仿外部数据的Token,但是SD要匹配的是Target的输出。

这个时候使用KD 就是很合理的了，训练drafter 匹配 完整target的token distribution， 看起来就能获得明显受益。

2. 而这个地方有一个问题，如果训练数据原本就是target写的的呢？

在这种情况下，普通CE训练的token大多就已经和 target的 greedy prediction 对齐。

这就让KD的纠正作用下降了。


# Introduction

1. 作者认为，现有的工作可能高估的 Loss Function的收益

很多文章比较 CE VS KD ， 然后发现KD可以显著提高acc， 于是宣称设计了更好的drafter 

但是如果CE学的是别的模型产生的token, KD 学的是target的模型的概率分布，那么KD天然具有一个优势。

它纠正了External responses 和 Target Outputs 之间的不一致

KD相比于普通CE，它还可以提供除了Top-1 Token之外的概率信息.

所以作者的想要证明的就是,KD 的收益在Target Regeneration 之后还剩下多少。

|Objective|  核心思想 |
| -- | -- |
| CE | 预测Corpus Token|
| KD | 模仿 Target的概率分布|
| KD + GATE | 排除Greedy verification中无法到达的位置|

最后给出的结论是：
**Target Regeneration 会显著缩小 KD 和 Survival Gate 相对于 CE 的额外收益，而且这种现象无法仅用训练数据变长来解释。**

其实相当于就是一般来说 CE学习的数据集是外部的，KD学的是target的，不是用 Target 数据后 KD 的绝对效果更差，而是用 Target 数据后，KD 相对于 CE 的优势大幅缩小。

# Experiment

这篇文章没啥好说的思维算法之类的，直接看看实验吧。

作者在CE, KD, KD + GATE 三个训练的目标函数下，处理了四种数据处理方式

- External: 原始外部模型生成的答案
- Full Regeneration: Target 自己重新生成答案
- Truncated 将Target 的生成答案截断到原答案长度
- Loss Window 保留完整生成答案，只监督原始答案等长度的前缀

后两种主要用于控制 Target Regeneration 让训练文本变长这个混杂变量。

# Result

1. Regeneration 显著削弱了KD的优势
即使控制监督长度，KD 的优势仍然明显小于 External 数据上的表现。
2. 有些 KD 增益来自 CE Baseline 退化
作者发现，在 External Corpus 上，随着训练 Epochs 增多，CE 的 MAT 反而下降得比 KD 更快。
也就是说，某些新 Loss 的增益还可能部分来自不够合理的 Baseline Training Schedule。
3. 不只是Dflash，作者发现在EAGLE3等也存在这个现象。

作者还做了一个Greedy - label control， 不用完整KD，而是直接将训练标签替换成Target在相同Prefix下预测的Greedy token。

结果在external corpus上
- 普通 CE -> greedy label CE 提高 9.3
- Greedy-label ce -> 完整KD: 提高 4.7

所以KD的一大部分收益来自于修正原始数据和 Target之间的监督不一致

而在 Target-regenerated Corpus 上，Greedy-label CE 相对普通 CE 已经没有可测量的额外收益。
