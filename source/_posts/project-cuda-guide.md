这里记录一下 CUDA Programming Guide 的简体中文整理项目。项目围绕 Release 13.3 组织内容，包含介绍、编程、进阶、特性、附录和参考部分。

站点使用 VuePress，提供章节导航和全文搜索。线程层级、执行方式和内存关系等内容也保留了相关图示，方便对照文字阅读。

翻译时需要注意术语的一致性，代码和 API 名称也要保持准确。尤其是涉及“仅当”“可能”“必须”的地方，少一个限定词就可能改变原意。

这是一份非官方中文整理，涉及行为保证、平台限制和版本差异时，建议对照对应版本的 NVIDIA 官方文档。站点、仓库和官方文档的链接放在下面。
