【暂时AIGC占位】CUDA 中文文档：除了翻译，还得让人找得到

发表于2026-10-11|更新于2026-10-11|项目

有时候，学一个东西的阻力并不完全来自它有多难。

也可能只是想查的那句话埋得太深，几个术语换着名字出现，刚刚看到的图一翻页又找不着了。尤其是 CUDA 这种文档，随便一个细节都能把人从当前章节拉到另一个章节去。

所以这份中文整理不只是把英文换成中文。至少我希望它能成为一个查得动、读得下去的入口。

先把路修通

项目围绕 CUDA Programming Guide Release 13.3 整理，内容目录覆盖介绍、编程、进阶、特性、附录与参考。站点使用 VuePress，把章节导航、全文搜索和阅读主题放到同一个地方。

图也不是装饰。线程层级、执行方式和内存关系，靠一大段文字去解释往往很费劲。保留官方文档中的相关图示，让它们和说明出现在一起，读的时候才能少一点来回翻找。

不过，排得好看不等于翻得准确。这两件事不能互相代替。

最容易偷懒的地方，反而最该认真

术语需要稳定。一个词在前面这样译，到了后面又换一种说法，读者很容易把它当成两个概念。代码、API 名称和限定条件也不能为了中文顺口就顺手改掉。

尤其是那些“仅当”“可能”“必须”。省掉一个，句子好像更干净了，意思却可能变了。

因此，中文稿的作用是降低阅读门槛，而不是替官方原文作最终解释。遇到涉及行为保证、平台限制或版本差异的地方，还是应当回到对应版本的 NVIDIA 文档核对。

一份能继续维护的笔记

仓库提供了文档开发和构建入口。把内容放在可维护的目录里，比留下一份很长、很难定位的文件更适合后续纠错。

现在的记录以仓库注明的版本为准，不把它称为永远最新，也不承诺翻译没有错误。这是非官方中文整理。

学东西已经够累了。能少迷一次路，也算有一点用。
